Detailed Description

High-order finite-difference stencils and dissipation operators used by the BSSN grid.

All evolution, geometry, and constraint kernels call into this header to evaluate spatial derivatives on the structure-of-arrays fields defined in Fields/BSSNGridSoA.hpp. Unless noted otherwise, operators are 4th-order accurate centered differences that require two guard cells on each side:

\[\partial_x f_{i,j,k} = \frac{-f_{i+2,j,k} + 8 f_{i+1,j,k} - 8 f_{i-1,j,k} + f_{i-2,j,k}} {12\,\Delta x}. \]

Second derivatives follow the standard \((-1,16,-30,16,-1)/12\) stencil, and mixed derivatives use either the classical 2nd-order cross operator (Dxy, Dxz, Dyz) or the 4th-order tensor-product version (Dxy4, Dxz4, Dyz4) when Ricci evaluations demand higher accuracy. Upwinded advection relies on biased 3-point formulas activated according to the sign of the local shift. Kreiss–Oliger dissipation implements the 6th-order filter used to stabilize high-frequency numerical noise in hyperbolic systems.

Note
These operators assume uniform spacing along each axis and share the units and conventions from BSSN_Grid. Callers are expected to clamp loop bounds so the stencil footprints never cross uninitialized halos.
