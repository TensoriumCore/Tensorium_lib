Detailed Description

Gauge drivers for \(\alpha\), \(\beta^i\), and \(B^i\) (1+log + Gamma-driver).

Documents Eq. (5.43) of Baumgarte–Shapiro: \((\partial_t-\mathcal{L}_\beta)\alpha=-2\alpha K\), and the hyperbolic shift driver \((\partial_t-\mathcal{L}_\beta)\beta^i = (3/4)B^i\), \((\partial_t-\mathcal{L}_\beta)B^i = (\partial_t\tilde{\Gamma}^i-\mathcal{L}_\beta\tilde{\Gamma}^i) - \eta B^i\).
