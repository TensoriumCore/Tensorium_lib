Detailed Description

RHS for the contracted connection \(\tilde{\Gamma}^i\).

Implements the standard BSSN equation with advection, metric-Laplacian of the shift, lapse coupling, and Ricci-driven source terms:

\[\begin{aligned} \partial_t \tilde{\Gamma}^i &= \beta^k\partial_k\tilde{\Gamma}^i - \tilde{\Gamma}^k\partial_k\beta^i + \tfrac{2}{3}\tilde{\Gamma}^i\partial_k\beta^k + \tilde{\gamma}^{jk}\partial_j\partial_k\beta^i + \tfrac{1}{3}\tilde{\gamma}^{ij}\partial_j\partial_k\beta^k \\ &\quad - 2\tilde{A}^{ij}\partial_j\alpha + 2\alpha\left(\tilde{\Gamma}^i_{\ jk}\tilde{A}^{jk} - \tfrac{2}{3}\tilde{\gamma}^{ij}\partial_j K\right) + \mathcal{D}_6[\tilde{\Gamma}^i]. \end{aligned} \]
