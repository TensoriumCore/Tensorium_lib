Detailed Description

RHS for the trace-free extrinsic curvature \(\tilde{A}_{ij}\).

Implements the trace-free part of

\[(\partial_t-\mathcal{L}_\beta)\tilde{A}_{ij} = \chi\left[-D_iD_j\alpha + \alpha R_{ij}\right]^{TF} + \alpha (K\tilde{A}_{ij} - 2\tilde{A}_{ik}\tilde{A}^k_{\ j}) \]

where \(D_i\) is the physical covariant derivative. The code reconstructs the physical metric \(\gamma_{ij}=\chi^{-1}\tilde{\gamma}_{ij}\) and Christoffels to evaluate the covariant Hessian of \(\alpha\).
