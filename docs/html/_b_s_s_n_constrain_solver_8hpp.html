Detailed Description

Bowen–York extrinsic curvature assembly and Lichnerowicz equation solver.

Binary puncture initial data require solving the Hamiltonian constraint in the conformally flat ansatz \(\gamma_{ij}=\psi^4\delta_{ij}\) with analytic \(\tilde{A}_{ij}\) constructed from prescribed linear momenta and spins (Bowen–York). This header provides routines to (1) add the momentum and spin pieces

\[\tilde{A}_{ij}^P = \frac{3}{2 r^2}(n_i P_j + n_j P_i - (\delta_{ij}-n_i n_j) n^k P_k),\qquad \tilde{A}_{ij}^S = \frac{3}{r^3}\epsilon_{k \ell(i} S^k n^{\ell} n_{j)} \]

and (2) solve \(\nabla^2 u + \frac{1}{8}\psi^{-7}\tilde{A}_{ij}\tilde{A}^{ij} = 0\) for the correction \(u\) to the conformal factor \(\psi = 1 + \sum_a m_a/(2 r_a) + u\) via red-black successive over-relaxation.
