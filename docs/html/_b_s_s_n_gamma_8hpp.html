Detailed Description

Contracted conformal connection diagnostics and construction utilities.

\(\tilde{\Gamma}^i = -\partial_j \tilde{\gamma}^{ij}\) in the BSSN formalism. The code maintains both an evolved \(\tilde{\Gamma}^i\) and a diagnostic divergence of \(\tilde{\gamma}^{ij}\) to track the algebraic Gamma constraint \(C^i\). These helpers evaluate the divergence without mutating the stored field so compute_bssn_constraints can compare the two and quantify violations.
