Detailed Description

Shared utilities (interior clamping helpers) for all RHS kernels.

Kernels call clamped_lower/upper to skip guard cells that halo/B.C. handlers may still be updating. Default padding of 4 ensures the ±2 (and ±3 KO6) stencils remain interior.
