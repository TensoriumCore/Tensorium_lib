Detailed Description

Builders for the Christoffel symbols \(\tilde{\Gamma}^i_{\ jk}\) and their contraction.

Both helpers restrict loops to interior points so that the 4th-order derivative operators have valid data. compute_tildeGamma_contracted recomputes the evolved \(\tilde{\Gamma}^i\) from the metric divergence to enforce the algebraic definition after projection steps. The compute_tildeGamma_symbols utility evaluates \(\tilde{\Gamma}^i_{\ jk}\) on demand without storing the full 27-component tensor, keeping the solver's memory footprint minimal.
