Detailed Description

Det( \(\tilde{\gamma}\)), trace-free, Gamma-constraint, and \(\chi\) monitors.

Projection routines guarantee \(\det\tilde{\gamma}=1\) and \(\mathrm{tr}\,\tilde{A}=0\) up to machine precision, but floating-point round-off and explicit RHS updates can reintroduce violations. This header provides statistics over the physical domain to quantify how close the numerical solution remains to the algebraic manifold. The tolerances scale with the stencil order (default 4th) and machine precision to avoid excessive false positives.
