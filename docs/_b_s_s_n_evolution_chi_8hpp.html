Detailed Description

RHS for the conformal factor equation \((\partial_t-\mathcal{L}_\beta)\chi = \frac{2}{3}\chi(\alpha K-\partial_i\beta^i)\).

The implementation evaluates

\[\partial_t\chi = \beta^i\partial_i\chi + \tfrac{2}{3}\chi(\alpha K-\partial_i\beta^i) + \mathcal{D}_6[\chi] \]

where advection uses third-order upwind stencils tied to the sign of each \(\beta^i\) component and \(\mathcal{D}_6\) is the KO6 dissipation.
